# Independent scene artwork

Nine original AI-generated illustrative assets made or edited for the 2026-10-09 Motion Vault art-direction task, plus one reproducible eight-second silent pan/zoom film for the two video-interface examples. These are not documentary photographs or licensed copies of reference-site photographs. See provenance.json for subjects, generation/editing source, processing and exact file hashes.

Only independent study runtimes use these files. Author-adapted examples retain their original asset boundaries. The shared build copies the assets into shared/art-direction and includes every resource hash in implementation versions. The four independent cloud examples copy only their required image subset and bind the original hashes separately.

The film is generated by scripts/build-art-film.mjs, not used as a substitute for interactive examples.
