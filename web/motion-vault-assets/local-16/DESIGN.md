## 使用场景

- 阅读与内容叙事 / 音视频与连续阅读：视频资料网格。不离开目录即可判断片段内容。

## 设计意图与构图

鼠标划过卡片缩略图，静态封面立刻无缝溶解为静音循环切片，移开即停。

不点进页面也能在 2 秒内摸清动效的手感与全貌，极大提高浏览效率。

## 运动与交互关系

hover video { opacity: 1; } hover img { opacity: 0; }

预览方式为auto。鼠标/拖拽/点击类的卡片运行本地代码，不以录屏假装跟手。

## 迁移时保留什么

不离开目录即可判断片段内容。将视觉变化绑定到用户正在操作的对象，保留开始、稳定和返回状态。

## 可以替换什么

文字、图像与业务数据可以替换；重新检查长文本、窄屏和布局比例。不要把演示中的业务词语或占位数据当作真实业务逻辑。

## 限制与验收

严禁发出任何声音！默认必须全静音（muted）。

以不同指针速度、反向操作、快速切换、Esc退出和减少动态效果测试。修改代码后重新生成封面/视频并核对版本，不沿用旧录屏冒充新实现。
