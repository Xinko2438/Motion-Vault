# 网格遮罩随悬停让出背景画面

## 实际用途
保留 Metalab 灵感原作的整幅图像网格、区域裁切与原生鼠标响应，背景媒体是素材层而非伪造交互的录屏。

保留原作整体图像、字块、遮罩和空间关系；不是为凑数新画的基础控件。适用于 portfolio / discovery。

## 源码及原作
https://github.com/codrops/HoverGrid

原作入口：http://tympanus.net/Development/HoverGrid/

## 接入边界
本项作为预选来源加入同一 Motion Vault。用户提拔、下架与恢复仍由原页面原存储控制。源码检查、构建成功不等于实际浏览器验收或用户审美接受。

## 视觉与迁移限制
未录制本地视频或本地封面，未宣称视觉一致性通过。保留作者素材与设计结构；外部字体回退可能改变字宽，需结合项目授权字体再次验收。
