# 散列字块汇聚成编排骨架

## 实际用途
小型信息字块、超大单字与留白形成编辑秩序；滚动驱动的不只是文字显隐，而是排版关系的持续重组。

保留原作整体图像、字块、遮罩和空间关系；不是为凑数新画的基础控件。适用于 editorial / typesetting。

## 源码及原作
https://github.com/codrops/ScrollTextMotion

原作入口：https://tympanus.net/Development/ScrollMotion/

## 接入边界
本项作为预选来源加入同一 Motion Vault。用户提拔、下架与恢复仍由原页面原存储控制。源码检查、构建成功不等于实际浏览器验收或用户审美接受。

## 视觉与迁移限制
未录制本地视频或本地封面，未宣称视觉一致性通过。保留作者素材与设计结构；外部字体回退可能改变字宽，需结合项目授权字体再次验收。
