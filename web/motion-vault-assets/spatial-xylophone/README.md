64 translucent capsule bars form a diagonal endless helix. The neutral, frosted body becomes a saturated spectral instrument only where the pointer wake excites it. The author combines blur-backed transmission, thin-film rims, inter-bar contact occlusion, damped strike rotation and an allocation-free GPU-consistent picker. A fixed camera and sloping silhouette make the composition legible while wheel or touch input turns the conveyor.

Real pointer sweep reveals tint and strikes a silent bar; wheel and vertical touch drag advance the helix. Original CPU picking, fluid splats and GPU strike timestamps are retained. No keyboard instrument route existed upstream.
